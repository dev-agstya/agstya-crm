
# कर्मचारी सहायता केंद्र (Employee Help Center)

कर्मचारी सहायता केंद्र में आपका स्वागत है। यहां बताया गया है कि आप अपने दिन-प्रतिदिन के कार्यों को कैसे प्रबंधित कर सकते हैं।

## 1. ग्राहक जोड़ना
**Breadcrumb:** डैशबोर्ड > ग्राहक > ग्राहक जोड़ें
**उपयोग कब करें:** जब आपको किसी नए लीड या क्लाइंट के लिए प्रोफ़ाइल बनाने की आवश्यकता हो।
**चरण-दर-चरण:**
1. साइडबार में ग्राहक (Customers) पर जाएं।
2. "ग्राहक जोड़ें" पर क्लिक करें।
3. उनकी व्यक्तिगत जानकारी, फोन नंबर और पता दर्ज करें।
4. ग्राहक रिकॉर्ड सहेजें।

## 2. पॉलिसी बनाना
**Breadcrumb:** डैशबोर्ड > नीतियां > पॉलिसी जोड़ें
**उपयोग कब करें:** जब कोई ग्राहक सफलतापूर्वक बीमा पॉलिसी खरीदता है।
**चरण-दर-चरण:**
1. नीतियां (Policies) पर जाएं।
2. उस ग्राहक का चयन करें जिसे आपने अभी जोड़ा है।
3. पॉलिसी विवरण भरें (बीमाकर्ता, पॉलिसी का प्रकार, प्रीमियम राशि)।
4. कोई भी आवश्यक दस्तावेज अपलोड करें।
5. पॉलिसी सहेजें।

## 3. दावा प्रसंस्करण
**Breadcrumb:** डैशबोर्ड > दावे > दावा दायर करें
**उपयोग कब करें:** जब किसी ग्राहक को बीमा दावा दायर करने की आवश्यकता हो।
**चरण-दर-चरण:**
1. दावे (Claims) अनुभाग पर जाएं।
2. ग्राहक की पॉलिसी खोजें।
3. "दावा दायर करें" पर क्लिक करें और घटना का विवरण दर्ज करें।
4. बीमाकर्ता से अपडेट प्राप्त होने पर दावे की स्थिति अपडेट करें।
